## 📌 Project Overview

This is a dynamic **Quiz Application** built using **pure HTML, CSS, and JavaScript (Vanilla JS)**.
The application allows users to select a difficulty level, answer multiple-choice questions, and track their performance in real time.

The project focuses on strong fundamentals of **DOM manipulation, event handling, and state management** without using any external libraries or frameworks.

---

## ✨ Features

* 🎯 **Difficulty Levels** (Easy / Medium / Hard)
* 🔀 **Randomized Questions & Answers**
* ⏱️ **Timer-based Question System**
* 📊 **Real-time Score Tracking**
* 📈 **Progress Bar Indicator**
* 🏆 **High Score Storage (localStorage)**
* 📱 **Responsive Design (Mobile + Desktop)**
* 🎉 **Final Score with Percentage & Feedback**

## ⚙️ How It Works

1. User selects a **difficulty level**
2. Questions are filtered and shuffled dynamically
3. Each question is displayed with multiple answer options
4. User selects an answer:

   * Correct → score increases
   * Incorrect → correct answer is highlighted
5. Timer counts down for each question
6. Progress bar updates as user advances
7. Final score and performance percentage are displayed
8. High score is saved using **localStorage**
